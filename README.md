SaafLoop is an Android app where anyone can photograph roadside waste and submit its location, even with limited internet. A verified volunteer group, NGO, or participating sanitation team can take the case, clean the site, and upload an after-photo. Residents confirm the result. If waste returns, the app links the new report to the same location so the community can address the recurring problem.

TECH STACK
- Kotlin, Jetpack Compose, Material 3, Navigation Compose
- Single-activity architecture, ready for MVVM
- minSdk 26, compileSdk 37, targetSdk 36
- Use compatible stable dependencies available to the project
- No backend, authentication, maps, or real reporting yet
